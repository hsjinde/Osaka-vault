## 南海電鐵 Rapi:t（ラピート）

關西機場（KIX）往返大阪難波的機場特急列車，由南海電鐵營運，50000 系車型。

- **所需時間：** 最快約 34 分鐘（關西機場→難波）
- **班距：** 約每 30 分鐘一班（全日上下各約 27 班）
- **路線：** 經南海本線，時速最高 120km/h
- **車廂：** 6 輛編成，全車指定席
- **官網：** <https://www.howto-osaka.com/tc/rapit/>
- **時刻表：** [南海電鐵官方 PDF](https://www.nankai.co.jp/lib/traffic/express/rapit/pdf/rairt_up.pdf)

### α 與 β 的差異

| 類型 | 特點 | 停靠站 |
|------|------|--------|
| **Rapi:t α** | 快速、停靠站少 | 關西機場 → 臨空城 → 泉佐野 → 天下茶屋 → 新今宮 → 難波（不停堺站） |
| **Rapi:t β** | 各站停靠型 | 關西機場 → 臨空城 → 泉佐野 → 岸和田 → 堺 → 天下茶屋 → 新今宮 → 難波 |

### 全停靠站

關西機場 → 臨空城 → 泉佐野 → 岸和田 → 堺 → 天下茶屋 → 新今宮 → 難波

### 使用規則

- **對象：** 12 歲以上，護照為「短期滯在」或觀光簽證（不適用日本國籍）
- **兒童：** 6–11 歲僅能現場購票；5 歲以下不佔位免費
- **購買限制：**
  - 單程票：最多 8 人 / 筆
  - 套票（含地鐵券）：最多 4 人 / 筆
  - 同一訂單須一起搭乘同一班列車
- **使用限制：** 非當日票方案 → 只能搭購買日的隔日起的列車（無法當天使用）
- **預約座位：** 購票後必須線上預約乘車日期、時間、車次與座位（最晚發車前 5 分鐘完成）；最多可變更 2 次
- **錯過列車：** 特急券失效、無法退費；但乘車券仍可轉搭普通列車
- **維護時段：** 每週二日本時間 3:00–4:30 停止預約服務
- **有效區間：**
  - 去程：關西機場站 → 堺 / 天下茶屋 / 新今宮 / 難波
  - 回程：難波 / 新今宮 / 天下茶屋 / 堺 → 關西機場站
- **QR 碼截圖無效**，須使用裝置上的電子正本，走「電子車票專用檢票機」

### 車內設備

- 車頂行李架 + 車廂間大型行李放置區
- 全車指定席，座椅間距 1,030mm、寬度 460mm
- スーパーシート為 2+1 配置（更寬敞）
- 免費 Wi-Fi、插座
- 各站均有廣播（中/英/日/韓）

### 注意事項

- 車票遺失不補發、不可重新兌換
- 中途下車不退差價
- 手機遺失 / 故障 / 沒電導致無法出示 → 無法使用且不退款
